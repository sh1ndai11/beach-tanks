# Beach Tanks

Онлайн 2D-игра: танки, вид сверху, пляж с укрытиями.
WASD — движение, пробел — огонь.

## Запуск локально
```
npm install
npm start
```
Открыть http://localhost:3000

## Деплой на Render (бесплатно)
1. Залей папку `tanks` в репозиторий на GitHub.
2. render.com → New → Web Service → выбрать репозиторий.
3. Build Command: `npm install`, Start Command: `npm start`, план Free.
4. Получишь ссылку вида `https://имя.onrender.com` — кидай друзьям.

(На бесплатном плане сервер засыпает без активности, первый вход после паузы грузится ~30–60 сек.)
